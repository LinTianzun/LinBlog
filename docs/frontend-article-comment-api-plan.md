# 前端文章与评论 API 接入计划（独立后续任务）

> 本文仅规划后续前端工作，不代表本次后端修复 PR 已完成前端接入。

## 文章页面

- [ ] 盘点文章列表、详情、编辑、新建、删除和状态操作页面。
- [ ] 为列表与详情建立 API 封装及 TypeScript/JSDoc 数据结构（按项目现有技术栈选择）。
- [ ] 统一处理分页、筛选条件、401/403/404 和服务器错误。
- [ ] 根据后端权限控制隐藏或禁用无权操作；后端仍是最终权限边界。
- [ ] 删除或状态更新成功后刷新列表/详情，并处理空列表与加载状态。
- [ ] 编写 API 层和页面交互测试。

## 评论页面

- [ ] 盘点文章详情评论列表、发表评论、二级回复和删除交互。
- [ ] 统一评论字段映射：评论 ID、文章 ID、父评论 ID、内容、作者和创建时间。
- [ ] UI 只提供一级评论和对一级评论的二级回复入口；后端继续强制校验层级。
- [ ] 处理内容长度上限、空白内容、已删除父评论和跨文章回复错误。
- [ ] 评论新增/删除后刷新或局部更新列表，并避免重复提交。
- [ ] 编写评论 API 与页面交互测试。

## 联调验收

- [ ] 使用测试环境 API 验证真实请求/响应结构。
- [ ] 验证无 Token、过期 Token、禁用账号 Token、无权限操作时的 UI 反馈。
- [ ] 记录 API 合约差异与待解决问题，不将未完成项标记为已接入。
