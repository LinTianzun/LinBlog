# LinBlog 开发进度

## 1. 项目概况

* 前端：`lin_blog/`，Vue 3、TypeScript、Vite、Pinia、Vue Router。
* 后端：`serve/`，Node.js、Express 5、MySQL、JWT、bcrypt；入口 `serve/linlog.js`。
* 数据库初始化：`serve/model/db/dbnew.js`。
* 文档更新日期：2026-10-23。

本表中的“已完成”只表示对应功能或验证范围有代码依据并通过所列检查，不代表整个项目已经可发布。未在真实数据库或浏览器端到端验证的功能，不标为已完成。

## 3. 已注册 API 概览

* 公开用户接口：`GET /api/user/isRegistered`、`POST /api/user/register`、`POST /api/user/login`。
* 认证用户接口：`POST /api/user/userInfo`。
* 用户管理（需管理员授权）：`POST /api/user/allUser`、`POST /api/user/createUser`、`PUT /api/user/updateUser/:id`、`DELETE /api/user/deleteUser/:id`、`PUT /api/user/updateUserStatus/:id`。
* 文章（需认证）：`GET/POST /api/article`、`GET/PUT/DELETE /api/article/:id`、`PATCH /api/article/:id/status`。
* 图片上传（需认证）：`POST /api/upload/image?token=...`，支持 JPG、PNG、WebP、GIF，单文件不超过 8 MB。
* 上传文件静态访问：`GET /api/uploads/:filename`。
* 评论（需认证）：`GET/POST /api/comment`、`DELETE /api/comment/:id`、`GET /api/comment/my`。
* 消息（需认证）：`POST /api/message`、`GET /api/message/inbox`、`GET /api/message/outbox`、`PATCH /api/message/read`、`DELETE /api/message/:id`、`GET /api/message/unread/count`。

路由注册见 `serve/routes/user.js`、`serve/routes/article.js`、`serve/routes/comment.js`、`serve/routes/message.js`、`serve/routes/upload.js`。文章和上传接口已完成前端接入；评论、消息等模块仍需逐项完成页面联调。

## 4. 发现的问题与待验证事项

1. **注册用户名冲突处理**：公开注册显式查邮箱但没有先查用户名；`users.username` 有唯一约束，重复用户名可能落入通用服务器错误，而非明确的冲突响应。
2. **用户统计标签与计算不符**：用户管理页用 `allTotal - roleCounts.admin` 显示“编辑与普通用户”，其中包含 `visitor`。后端列表响应已经提供角色分布，可据此修正。
3. **其余内容模块仍使用 Mock**：评论、消息以及分类、标签、文件、图库、日记、天气和统计仍有页面读取 `src/mock/data.ts`。文章模块完成不代表这些模块已接通真实接口。
4. **上传文件生命周期不完整**：图片保存在 `serve/data/img/`，删除或替换文章封面不会清理旧文件，也没有定期清理、备份或云存储同步机制。长期运行可能产生孤儿文件。
5. **上传 Token 暴露风险**：`yk-upload` 通过查询参数携带 JWT，Token 可能进入服务器访问日志、代理日志或浏览器历史。当前实现受上传组件限制，但部署时应避免记录完整 query，并评估短期上传专用 Token。
6. **数据库初始化仍应隔离验证**：后端启动会调用初始化逻辑，首次初始化可能建库、建表和插入演示数据；后续启动仍可能执行增量 DDL。不能在有价值的数据上通过删除标记或重置来测试。
7. **真实 MySQL 与浏览器覆盖仍有限**：后端 38 项测试多使用模型替身，不能替代真实 MySQL、迁移、权限组合、上传失败分支和跨浏览器上传验证。
8. **打包警告**：本次构建成功，但 MockJS 包含 `eval` 警告，且 OverView / EditArticle 等生成 chunk 超过 500 KB。需确认 MockJS 的保留范围并评估按页面或编辑器拆包。
9. **跨域部署仍需实测**：CORS 代码已配置允许来源、`Authorization` 和 `PATCH`，但当前结论主要基于开发环境的 Vite 同源代理；正式域名、HTTPS 和反向代理场景仍需执行 OPTIONS 预检验证。
