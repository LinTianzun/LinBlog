# LinBlog 开发进度

## 1. 项目基本信息

* 前端目录：`lin_blog/`
* 后端目录：`serve/`
* 项目文档目录：`Documentation/`
* 前端技术栈：Vue 3、TypeScript、Vite、Pinia、Vue Router
* 后端技术栈：Node.js、Express 5、MySQL、mysql2、JWT、bcrypt
* 后端入口：`serve/linlog.js`
* 数据库初始化文件：`serve/model/db/dbnew.js`

## 3. 当前问题与风险

1. **前端构建失败**：`npm run build` 在 `vue-tsc -b` 阶段报告多处错误。用户管理页的 API 返回值被推断为 `AxiosResponse`，但页面读取 `result.code`/`result.message`；`countByRole` 未使用。文章、文件、日记等既有组件也有类型错误。需先建立可通过的类型检查/构建基线。
2. **用户编辑功能未闭环**：用户管理编辑表单没有提交处理函数，后端也没有更新用户路由、控制器或模型。“编辑与普通用户”统计通过总用户数减管理员数计算，会把游客一并计入。相关文件：`lin_blog/src/views/UserManagement.vue`、`serve/routes/user.js`。
3. **文章所有者字段需迁移验证**：`article.user_id`、索引、外键及启动时增量迁移已加入；迁移未在真实数据库执行。旧文章作者保持 `NULL`，不会自动推断或回填。相关文件：`serve/model/db/dbnew.js`。
4. **前后端文章契约不一致**：前端编辑器传数字状态和 `classify: 0`，后端接口接受 `draft/published/rejected` 和 `article/image`；前端数据类型也与后端字段命名不同。相关文件：`lin_blog/src/views/EditArticle.vue`、`lin_blog/src/utils/interface.ts`、`serve/controller/articleController.js`。
5. **认证与配置需复核**：认证中间件未见拒绝禁用账号；注册流程需确认用户名重复时返回明确错误；JWT 密钥在 `serve/config/default.js` 中硬编码；`serve/linlog.js` 使用 `config.allowedOrigins`，但当前配置未定义该项。
6. **初始化幂等性未经验证**：`.mock_data_inserted` 检查函数没有参与初始化决策；首次初始化是否执行建表/种子数据由 `.db_initialized` 决定。标记和数据库状态不一致或首次初始化中途失败时的行为待验证。不要在现有数据库上删除标记或重置来验证。
7. **其余模块及运行验证未完成**：分类、文件上传、图库、日记、天气、统计等页面仍有 Mock；后端没有统一的启动/测试脚本。模型测试使用查询替身，不代替真实 MySQL 或 HTTP 接口测试。
