## 1. 项目概况

* 前端：`lin_blog/`，Vue 3、TypeScript、Vite、Pinia、Vue Router。
* 后端：`serve/`，Node.js、Express 5、MySQL、JWT、bcrypt；入口 `serve/linlog.js`。
* 数据库初始化：`serve/model/db/dbnew.js`。
* 文档更新日期：2026-10-25。

本表中的“已完成”只表示对应功能或验证范围有代码依据并通过所列检查，不代表整个项目已经可发布。未在真实数据库或浏览器端到端验证的功能，不标为已完成。

## 4. 发现的问题与待验证事项

1. **注册用户名并发冲突路径**：公开注册已显式检查邮箱与用户名重复（重复返回 400 冲突提示），但并发插入仍可能触发唯一键冲突并落入通用 500，错误路径待补测。
2. **用户统计标签与计算不符**：用户管理页用 `allTotal - roleCounts.admin` 显示“编辑与普通用户”，其中包含 `visitor`。后端列表响应已经提供角色分布，可据此修正。
2. **访问统计口径与治理**：访问记录从功能上线起积累，历史数据为空；`record.position` 暂未接 IP 地理解析库；“数据监测”饼图的来源维度使用操作系统分布替代原 Mock 的站点来源。持续写入无清理策略，长期需考虑归档或滚动删除。
3. **上传文件生命周期不完整**：图片保存在 `serve/data/img/`，删除或替换文章封面不会清理旧文件，也没有定期清理、备份或云存储同步机制。长期运行可能产生孤儿文件。
4. **上传 Token 暴露风险**：`yk-upload` 通过查询参数携带 JWT，Token 可能进入服务器访问日志、代理日志或浏览器历史。当前实现受上传组件限制，但部署时应避免记录完整 query，并评估短期上传专用 Token。
5. **数据库初始化仍应隔离验证**：后端启动会调用初始化逻辑，首次初始化可能建库、建表和插入演示数据；后续启动仍可能执行增量 DDL。不能在有价值的数据上通过删除标记或重置来测试。访问统计聚合 SQL 已在隔离库实测，但完整业务流仍待隔离集成测试。
6. **真实 MySQL 与浏览器覆盖仍有限**：后端 104 项测试多使用模型替身；真实 MySQL 集成测试已建立（`LINBLOG_INTEGRATION_DB` 机制），可按需扩展迁移、权限组合、上传失败分支的覆盖，跨浏览器上传验证仍未进行。
7. **打包警告**：本次构建成功，MockJS `eval` 警告已随依赖移除消失；OverView（约 549 KB）/ EditArticle（约 819 KB）等生成 chunk 仍超过 500 KB，需评估按页面或编辑器拆包。
8. **跨域部署仍需实测**：CORS 代码已配置允许来源、`Authorization` 和 `PATCH`，但当前结论主要基于开发环境的 Vite 同源代理；正式域名、HTTPS 和反向代理场景仍需执行 OPTIONS 预检验证。
