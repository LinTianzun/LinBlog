# LinBlog 开发进度

## 1. 项目概况

* 前端：`lin_blog/`，Vue 3、TypeScript、Vite、Pinia、Vue Router。
* 后端：`serve/`，Node.js、Express 5、MySQL、JWT、bcrypt；入口 `serve/linlog.js`。
* 数据库初始化：`serve/model/db/dbnew.js`。
* 文档更新日期：2026-10-21。

本表中的“已完成”只表示对应功能或验证范围有代码依据并通过所列检查，不代表整个项目已经可发布。未在真实数据库或浏览器端到端验证的功能，不标为已完成。

## 3. 已注册 API 概览

* 公开用户接口：`GET /api/user/isRegistered`、`POST /api/user/register`、`POST /api/user/login`。
* 认证用户接口：`POST /api/user/userInfo`。
* 用户管理（需管理员授权）：`POST /api/user/allUser`、`POST /api/user/createUser`、`PUT /api/user/updateUser/:id`、`DELETE /api/user/deleteUser/:id`、`PUT /api/user/updateUserStatus/:id`。
* 文章（需认证）：`GET/POST /api/article`、`GET/PUT/DELETE /api/article/:id`、`PATCH /api/article/:id/status`。
* 评论（需认证）：`GET/POST /api/comment`、`DELETE /api/comment/:id`、`GET /api/comment/my`。
* 消息（需认证）：`POST /api/message`、`GET /api/message/inbox`、`GET /api/message/outbox`、`PATCH /api/message/read`、`DELETE /api/message/:id`、`GET /api/message/unread/count`。

路由注册见 `serve/routes/user.js`、`serve/routes/article.js`、`serve/routes/comment.js`、`serve/routes/message.js`。接口已注册不代表前端已接入，也不代表已通过真实 HTTP 测试。

## 4. 发现的问题与待验证事项

1. **CORS 配置与接口不一致**：`serve/linlog.js` 读取 `config.allowedOrigins`，但 `serve/config/default.js` 未定义；CORS 的 `allowedHeaders` 未列 `Authorization`，`methods` 未列 `PATCH`。Vite `/api` 同源代理不能证明跨域部署的预检请求可用。
2. **环境变量使用说明易误导**：`serve/.env.example` 是模板，`default.js` 只读 `process.env`，代码未自动加载 `.env`。仅创建 `.env` 后执行 `node linlog.js` 不会自动设置密钥；密钥缺失或少于 32 字符会在加载配置时抛错。需明确启动环境变量设置流程。
3. **注册用户名冲突处理**：公开注册显式查邮箱但没有先查用户名；`users.username` 有唯一约束，重复用户名可能落入通用服务器错误，而非明确的冲突响应。
4. **用户统计标签与计算不符**：用户管理页用 `allTotal - roleCounts.admin` 显示“编辑与普通用户”，其中包含 `visitor`。后端列表响应已经提供角色分布，可据此修正。
5. **内容页面尚未切换到真实数据**：文章请求封装存在但页面未使用；评论/消息以及分类、标签、文件、图库、日记、天气和统计仍有 Mock 数据。页面 UI 不应被视为接口完成。
6. **数据库初始化需隔离验证**：后端启动调用初始化逻辑，首次初始化可能建库、建表和插入演示数据；后续启动仍可能对文章表执行增量 DDL。`checkMockDataInserted` 有定义，但没有参与初始化判断。不能在有价值的数据上通过删除标记或重置来测试。
7. **打包警告**：本次构建成功，但 MockJS 包含 `eval` 警告，且 OverView / EditArticle 等生成 chunk 超过 500 KB。需确认依赖使用必要性并评估合理拆包。
8. **测试覆盖有限**：目前只有文章模型查询替身测试；用户名冲突、管理员权限、禁用账号 token、CORS 预检、迁移以及用户/文章真实 HTTP 流程均待测试。
