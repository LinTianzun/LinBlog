# Pixel farm sprites

The pet homestead uses **Tiny Farm** by Kenney.

- Source: https://opengameart.org/content/tiny-farm
- License: CC0 1.0 Universal (public domain)
- Usage here: house, animals, crops, trees and farm props in the pet homestead.

The original tilesheet is 16×16. Extracted PNGs live in `pixel/`; the pack license
is kept in `pixel/License.txt`.
